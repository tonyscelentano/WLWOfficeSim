> *"Have you tried turning it off and never coming back?"*

**OfficeSim** is a quirky, LLM-driven office lifestyle simulator where every coworker has a
personality, an agenda, and at least one unresolved crisis. Navigate the fluorescent hellscape of
open-plan cubicle life, attend meetings that could have been emails, and confront the crushing
existential weight of the 9-to-5 — one passive-aggressive Slack message at a time.

---

## ✨ Features

- **LLM-powered characters** — a wide cast of coworkers, each with distinct personalities,
  quirks, and deeply questionable life choices, all driven by live AI dialogue
- **Absurdist office humor** — mandatory fun, pointless synergies, and the slow spiritual
  erosion of performance reviews
- **Emergent storylines** — your choices ripple through the office ecosystem in ways HR
  definitely wasn't prepared for
- **Rich cast of characters** — from the suspiciously cheerful intern to the manager who
  schedules a meeting to discuss the meeting
- **Tons of existential flavor** — because nothing says "modern life" like debating your
  purpose while the printer jams *again*

## 🚀 Getting Started

### Requirements

- **NVIDIA API Key** (currently required) — sign up for free at
  [build.nvidia.com](https://build.nvidia.com)

> **Note:** NVIDIA NIM API keys are free to obtain. OfficeSim uses NVIDIA's API to power
> all in-game character dialogue. Support for additional LLM providers is on the roadmap.

### Installation

```
# Clone the repo
git clone https://github.com/yourusername/OfficeSim.git

# Navigate to the project folder
cd OfficeSim

# Follow setup instructions in /docs or the in-game tutorial
```

### Configuration

Add your NVIDIA API key to the config file or environment before launching:

```
NVIDIA_API_KEY=your_key_here
```
